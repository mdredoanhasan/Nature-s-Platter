# Nature's Platter

## 📖 Overview
Nature's Platter is a responsive grocery e-commerce landing page showcasing daily essentials, fresh produce, and special offers. It was built as a practice project to strengthen my HTML and Tailwind CSS skills.

🔗 **Live Site:** [https://mdredoanhasan.github.io/Nature-s-Platter/](https://mdredoanhasan.github.io/Nature-s-Platter/)

## 🛠️ Built With
- HTML5
- Tailwind CSS

## ✨ Key Features
- Navigation bar with login/register
- Hero section with call-to-action
- Services section (24/7 Service, Fast Delivery, Healthy Products)
- Popular products showcase with pricing and ratings
- Arrivals & offers section
- Newsletter subscription section
- Footer with social links

## 📦 Dependencies
- [Tailwind CSS](https://tailwindcss.com/) — utility-first CSS framework

## 🚀 Getting Started (Run Locally)
1. Clone the repository:
```bash
   git clone https://github.com/mdredoanhasan/Nature-s-Platter.git
```
2. Navigate into the project folder:
```bash
   cd Nature-s-Platter
```
3. Open `index.html` directly in your browser, or use the **Live Server** extension in VS Code for auto-reload.
